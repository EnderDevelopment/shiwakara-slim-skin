# Minecraft Slim Texture: Shiwakara Slim Skin

Shiwakara Slim Skin is a detailed 64x64 Minecraft texture for the slim player model, featuring Run Shiwakara-inspired dark clothing, red accents, cyan highlights, styled hair, facial details, armor-like overlays, and slim arms.

## Install

1. Download or clone this repository.
2. Open `assets/textures/run_shiwakara_slim.svg` in an SVG-compatible graphics editor.
3. Export the texture at exactly 64x64 pixels as a PNG file.
4. Keep the exported image at 64x64 pixels without smoothing or interpolation.

## Use

1. Open Minecraft's skin customization or skin upload screen.
2. Select the slim model option.
3. Upload the exported PNG texture.
4. Apply the skin and preview it in-game.

The included source texture is an SVG file. Minecraft skin uploaders generally require PNG files, so export the SVG to PNG before applying it.
